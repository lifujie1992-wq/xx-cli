# taobao_publish.mjs —— 淘宝发布商品自动化

把抓来的 `cli_goods_*.json` 一键发布到你的千牛小店。

脚本位置: `~/xx-cli/taobao_publish/taobao_publish.mjs`
商品数据(cli_goods_*.json)通常在 `~/Downloads/商品抓取CLI/`,用参数传路径即可。

## 用法
```bash
# 前置: CloakBrowser 已开(CDP 9223)且已登录卖家后台
cd ~/xx-cli/taobao_publish
node taobao_publish.mjs ~/Downloads/商品抓取CLI/cli_goods_20260618.json --no-submit # 填到确认页,看「全绿 ✅」(第一次推荐)
node taobao_publish.mjs ~/Downloads/商品抓取CLI/cli_goods_20260618.json             # 确认无误后自动提交上架
node taobao_publish.mjs ~/Downloads/商品抓取CLI/cli_goods_20260618.json --draft     # 只存草稿
```
注: playwright 依赖在 `~/node_modules`,脚本放哪都能跑(node 向上查找)。

## 它做了什么
选类目(全新发布,**不用发布相似品**——那个锁类目) → 标题 → 材质成分 → 类目属性 → 颜色/尺码SKU → 价格库存 → SKU裙长/图案 → 主图(竖图补白成1:1重传) → 详情图 → 物流(使用物流配送+包邮模板+48h) → 提交。

## 换商品/换类目要改的地方(文件顶部 CONFIG / PROP_MAP)
- `categoryKeyword`:类目搜索词(默认「半身裙」)。换品类改这里。
- `freightTemplate`:运费模板名(店铺里要先存在,默认「全国包邮」)。
- `skuDefaults.裙长 / 图案`:JSON 没有尺寸数据,必填,先填兜底值,**上架后记得核对改准**。
- `PROP_MAP`:JSON 属性名 → 表单属性标签 + 控件类型。**换类目时类目属性不同,需对照新类目的属性增删/改标签。**
  属性的具体选项是按「文本」实时匹配页面下拉的(不写死 id),所以同类目换商品直接可用。

## 已知坑(踩过的)
1. **发布相似品锁死类目**,跨类目发不了 → 本脚本走「发布商品」。
2. **Fusion 下拉必须真实鼠标点击**才打开,选项在 `.options-item`(自定义弹层,不是标准 menu)。
3. **主图竖图(3:4)会被 1:1 槽拒**(图片类型不符)→ 用 sips 补白成方图再传。
4. **SKU 必填漏点**:每个 SKU 要填「裙长 + 图案」,走「更多批量」对话框。
4b. **批量价格/库存有毒坑(重要)**:批量行的「批量填写」要求价格+数量都填,但**每次只生效先填的那个字段**。
    所以必须**两趟**:① 价格先填→批量填写(价格生效)② 数量先填→批量填写(库存生效,价格保留)。
    脚本已这么做。单趟无论顺序都会漏掉一个。
4c. 尺码/价格库存/运费这 3 步都做了「填完读 `__SELL_STATE__` 校验 + 失败重试」,跑完看日志末尾「自检…→ 全绿 ✅」。
5. **运费**:要勾的是「**使用物流配送**」(不是那个禁用的电子凭证 checkbox),勾后选运费模板。
6. **图片上传**走 `本地上传` 触发原生 filechooser;选图是点图块缩略图(最新上传的在画廊最前)。
7. 不确定还缺什么时,点一次「提交宝贝信息」让左侧「优化建议 错误(N)」把所有缺失项列出来。

## 局限
- 详情图顺序按画廊顺序(非严格 01→10),如在意可在详情编辑器拖动调整。
- 尺寸(身高/体重/腰围/裙长)是兜底估值,JSON 无此数据;精确尺码请人工补。
- 图片是源卖家的图(盗图风险),长期建议换自己拍的图。
